# Historical investigation scripts

These are byte-preserved snapshots of one-off investigations, not supported
commands. They may contain hardcoded environments, old identities, fixed output
paths or browser actions with side effects. Do not execute them as readiness or
regression tools. inventory.json maps original paths and content hashes; no
historical run outcomes have been rewritten. Captures/resources are preserved.

Use tools/cli.cjs doctor, quickship-readiness, quickship-refresh or live for
maintained operations. Generic browser discovery is under tools/discovery and
requires its own explicit action scope. Interactive login remains the scoped
scripts/refresh-quickship-session.cjs. Historical text references to the original
script paths identify evidence producers and are not current command guidance.
